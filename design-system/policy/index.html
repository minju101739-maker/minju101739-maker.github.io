이름 규칙

프로젝트(파운데이션 모델, 모델 배포, RAG, 워크플로우, 데이터 파이프라인, 리포트)의 이름에 같은 규칙을 적용한다. 프로젝트 이름은 제한을 최소로 두고, 데이터 관리의 폴더 이름으로도 쓰이므로 경로 구분자만 막는다. 도구, 폴더, 변수, 권한 유형과 항목의 이름은 각 생성 모달의 검사를 따른다.

화면과 기능이 함께 따르는 규칙이다. 값은 4340 화면 코드와 기획 정본에서 옮겼다.

입력 규칙

  • 글자 종류와 첫 글자는 제한하지 않는다. 자음이나 모음만 있는 글자(ㅇ, ㅏ)와 특수 문자도 쓸 수 있다.
  • 경로 구분자(/, \)는 쓸 수 없다.
  • 길이는 1~100자다. 앞뒤 공백은 지우고 집계한다.
  • 같은 대상 안에서 이름이 겹치면 차단한다. 대소문자는 구분하지 않는다.
  • 설명은 선택 항목이고 500자까지다.

검사 차례

위에서부터 검사해 먼저 걸린 하나만 모달 바닥 안내에 빨간 텍스트로 표시하고, 칸은 빨간 테두리로 표시한다. 칸 아래에는 같은 문장을 다시 두지 않는다. 문구의 따옴표 안에는 입력값에서 걸린 글자를 그대로 넣는다.
