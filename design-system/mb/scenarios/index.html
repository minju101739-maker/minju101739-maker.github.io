수집에서 데이터셋 버전 발행까지웹 문서를 수집해 데이터 관리에 모으고, 분석으로 분포를 확인한 뒤 라벨링(오토라벨링, 검수)과 전처리를 거쳐 데이터셋 버전을 발행한다.1430
데이터 파이프라인 설계에서 자동 업데이트까지수집, 분석, 오토라벨링, 검수, 전처리, 버전 생성 노드를 이은 데이터 파이프라인을 설계해 실행하고, 검수 뒤 발행된 데이터셋 버전을 확인한 다음 신규 데이터량 기준 자동 업데이트를 켠다.618
학습에서 배포, 엔드포인트 연결, 테스트까지빌트인 모델, Hugging Face 모델, 자동 학습(지도 학습)으로 학습하고 결과와 리더보드를 비교한 뒤, 고른 모델을 배포해 워커를 실행하고 엔드포인트를 연결해 테스트에서 호출한다.1223
모델 파이프라인으로 재학습과 재배포데이터셋 노드, 학습 노드, 배포 노드를 이은 모델 파이프라인을 만들고 데이터셋 버전 기준 자동 업데이트를 켜서, 새 데이터셋 버전이 발행되면 재학습하고 배포 조건을 넘은 모델을 다시 배포한다.715
권한 없는 AI 개발자의 요청과 관리자 승인컴퓨팅 자원 사용 권한이 없는 AI 개발자가 학습 실행을 요청하고, 관리자가 승인하면 요청한 값으로 자동 실행된다. 거절(검토 메모), 요청 취소, 다운로드 승인(7일, 한 번 사용), 승인 대기 중 삭제 차단을 함께 확인한다.913
개발 환경에서 코드와 이미지를 커밋해 학습에 쓰기개발 환경을 만들어 학습 코드를 작성하고 코드 커밋과 도커 이미지 커밋을 한 뒤, 커스텀 학습 실행 창에서 그 이미지와 실행 코드를 골라 학습을 실행한다.813
GPU 부족과 대기, 자원 한도 변경 요청노드 풀 잔여보다 많은 GPU 를 요청한 학습이 대기로 들어가는 것을 확인하고, 대시보드와 시스템 자원 관리에서 대기 사유를 본 뒤 자원 한도 변경을 요청한다.510
