03. 작업 상태

모든 작업은 아래 상태 중 하나입니다. 대기와 실패는 상태를 선택하면 사유를 볼 수 있습니다.

01생성됨

작업을 만든 뒤 아직 [배포]나 [실행]을 하지 않아 자원을 점유하지 않은 상태입니다.

02대기

자원 부족, 관리자 승인, 지정 시각이나 피크외 시간 때문에 실행을 기다리는 상태이며 상태를 선택하면 대기 사유를 볼 수 있습니다.

03설치중

자원을 할당받아 가져오고 실행 환경을 설치하는 단계이며 이 단계가 끝나면 실행중으로 바뀝니다.

04실행중

학습이나 데이터 처리가 진행되거나 배포한 모델 배포, RAG, 도구, 워크플로우가 호출을 받을 수 있는 상태입니다.

05종료

학습처럼 스스로 끝나는 작업이 정상으로 끝난 상태이며 배포한 작업은 종료 대신 중지가 됩니다.

06중지

사용자가 [배포 중지]나 [중지]로 멈춘 상태이며 점유하던 자원은 반환됩니다.

07실패

실행이 에러로 끝난 상태이며 상태를 선택하면 에러 로그와 점유 중인 자원 같은 실패 사유를 볼 수 있습니다.

04. 만들기와 배포

작업을 만들어도 자원은 쓰지 않습니다. 자원은 [배포]나 [실행]을 선택할 때 받습니다.

01생성

작업을 만들면 생성됨 상태입니다. 자원을 점유하지 않습니다.

02배포

모델 배포, RAG, 도구, 데이터 파이프라인은 [배포]로 자원을 받아 실행합니다.

03실행 시점

즉시 실행, 지정 시각, 피크외 시간 중 선택합니다. 자원이 모자라면 대기합니다.

04배포 중지

자원을 반환합니다. 만든 데이터와 설정은 남습니다.

05외부 모델

외부 엔드포인트와 상용 API는 자원 없이 주소와 API Key만 등록합니다.

05. 권한과 승인 요청

구성원 권한대상 작업관리자일반 사용자(권한 있음)일반 사용자(권한 없음)

다운로드데이터 파일과 데이터셋, RAG 문서, 커밋, 학습 지표, 로그, 리포트바로 실행바로 실행승인 요청 → 승인 뒤 요청자가 직접 받음
