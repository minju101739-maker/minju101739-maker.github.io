색

색마다 역할, 쓰는 부품과 화면, 사용 수, 토큰 밖 색. 값의 정본은 src/design-system/tokens.ts 와 spec.ts 이고 이 화면은 그 파일을 그대로 읽는다.

색의 역할과 사용 현황

색마다 역할과 쓰는 위치를 정하고, 4340 화면에서 실제로 쓰는 부품과 화면을 함께 적었다. 사용 현황을 불러오는 중. 규칙은 「화면에서는 헥스 값을 직접 쓰지 않고 색 토큰을 쓴다」이다. 예외는 메뉴와 로고 SVG 의 원본 색이다. 그래프 계열 색은 작업 유형 색(moduleColor)과 상태 색(ok, warn, danger, accent) 차례로 쓴다. 지금 헥스를 직접 적은 곳은 -곳이다(맨 아래 표).

배경색 지도

4340 화면 한 장에서 배경을 칠한 위치마다 번호를 달았다. 번호를 아래 표에서 찾으면 색, 헥스 값, 토큰, 코드에 적힌 클래스가 나온다. 흰색에 가까운 배경이 여러 단계라 눈으로는 구별하기 어렵다. 헥스 값으로 구별한다.
