서비스 로직작업과 회차를 관리하고 권한 판정, 승인 요청, 편집 점유, 작업 이력, 알림, 크레딧 환산을 처리한다.작업·회차 관리, 권한 판정·승인, 편집 점유, 이력·알림, 크레딧 환산

외부 연결

대상연결 내용
서비스 API외부 서비스가 오픈한 워크플로우를 호출하고 답변의 피드백을 보낸다. 서비스 키와 권한 설정으로 통제한다. AGENTBASE 하나에 서비스 하나를 둔다.
사용자 권한 API서비스가 사용자 속성과 권한 유형, 항목을 보낸다. 시스템은 동기화로 가져와 권한 판정에 쓴다.
오케스트레이터GPUBASE 가 연결하는 대화형 모델 배포 하나다. 연결되면 홈에서 대화로 워크플로우, RAG 생성과 노드 추가를 요청한다.
외부 모델·도구외부 엔드포인트와 상용 API 모델은 모델 배포로 등록하고, 외부 REST API 와 MCP 서버는 도구로 등록한다.

구현 선택

항목
메타데이터 DB 의 제품과 테이블 분할. 이 문서는 엔티티와 관계만 정하고 관계형 저장을 전제로 한다.
파일 스토리지의 방식. GPUBASE 가 할당한 저장 공간 위에 원본 데이터, 데이터셋 버전, 체크포인트를 경로로 구분해 둔다.
작업 대기열과 스케줄러. 자원이 모자라면 대기로 두고 자원이 반환되면 실행한다는 규칙만 정한다.
검색 DB 엔진, 추론 엔진, 학습 프레임워크. 선택 항목의 값 범위와 기본값은 개발 문서가 정한다.
서비스 로직과 화면 사이의 API 형식과 인증 방식.
