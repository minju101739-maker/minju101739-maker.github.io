페이지 01 목록 화면 · List Page

모듈의 작업이나 자원을 목록으로 조회하고 필터, 검색, 정렬을 적용한다.

규칙(화면 설계서 6장) · 목록 머리, 필터 줄, 목록 카드, 표, 페이지 크기, 빈 상태

목록 머리

  • 목록 화면은 제목, 필터 줄, 표 또는 카드 순서로 배치한다. 제목 줄과 필터 줄 사이는 24이다.
  • 생성 버튼은 제목 줄 오른쪽 끝에 하나만 둔다. 제목 줄 바로 아래에 필터 줄을 둔다.
  • 보조 동작(새로 고침, 다운로드)은 같은 줄에 quiet 유형으로 두고, 셋을 넘으면 더보기 메뉴로 묶는다.
  • 카드 목록은 생성 버튼과 첫 칸의 생성 타일 가운데 하나를 쓴다.
  • 개수는 제목 옆 또는 필터 줄 왼쪽 끝 중 한 곳에만 표시한다.
  • 부제에는 다음에 할 일을 쓴다.

필터 줄

  • 필터 줄 왼쪽에는 개수, [내 프로젝트]를, 오른쪽에는 상태와 유형 필터, 검색, 정렬을 순서대로 둔다. 오른쪽 그룹은 오른쪽 끝에 배치한다.
  • 개수 칸의 폭은 44로 고정한다.
  • 검색칸은 입력 안내 글자 하나로 검색 대상(예: 모델 이름 검색)을 표시한다.

목록 카드

  • 카드는 위에서부터 출처 칩과 상태 칩, 소유자, 제목, 부제, 설명, 최근 시각 순서로 배치한다.
  • 설명이 비어 있으면 "작성된 설명이 없습니다"를 표시한다.
  • 선택 항목이 비어 있는 칸은 "작성된 {항목}이 없습니다."를 회색으로 표시한다. 상세 정보의 이름표와 값 목록도 같다.
  • 카드 너비는 300으로 고정하고 창 폭에 들어가는 카드 수로 칸 수를 정한다.
  • 생성 진입은 격자 첫 칸의 생성 타일로 둔다.

표

  • 표는 본문 배경 위에 줄 구분선으로 구성한다.
  • 행 높이는 목록 56, 상세 탭 48, 창 35로 쓴다.
  • 행 안의 조작은 글자 링크로 표시한다(미리보기, 다운로드, 메타데이터, 삭제). 한 칸에 조작이 둘 이상이면 16 간격으로 배치한다(RowActions).
  • 표의 왼쪽 정렬 열에 아이콘 버튼나 글자 버튼을 둘 때는 버튼을 칸 안에서 왼쪽으로 당겨 아이콘이나 글자의 시작점을 머리글 글자의 시작점과 맞춘다(아이콘 버튼 8px, 글자만 있는 버튼 9px). 조작 열(메타데이터, 다운로드, 삭제)도 왼쪽으로 정렬한다.
  • 다운로드는 한 건이면 행의 다운로드 아이콘, 여러 건이면 선택 상자로 고른 뒤 표 아래 왼쪽 [다운로드]로 압축 파일 하나를 받는다. 선택 상자가 없는 표(RAG 데이터, 리포트)는 행 아이콘만 둔다. 행 아이콘도 파일 다운로드 권한을 거친다.
  • 빈 상태 문구와 오류 문구를 구분해 표시한다.
  • 값이 비어 있는 칸은 "-"로 표시한다. 선택 항목이 비어 있는 칸은 "작성된 {항목}이 없습니다."를 회색으로 표시하고, 칸이 좁으면 말줄임과 말풍선으로 표시한다.
  • 1024 미만에서도 모든 열을 표시하고 표 영역 안에서 가로로 스크롤한다. 표 안의 이름은 줄바꿈해 모두 표시한다.

페이지 크기

  • 목록 보기는 영역 높이를 줄 높이로 나눈 수를 한 페이지의 줄 수로 표시한다.
  • 카드 보기는 한 줄에 표시되는 카드 수와 영역에 들어가는 카드 줄 수를 곱한 수를 한 페이지의 카드 수로 표시한다.
  • 목록 보기와 카드 보기는 한 페이지 수를 따로 계산하고, 영역은 높이를 고정한다. 한 페이지이면 페이지 넘김은 마지막 줄 바로 아래, 여러 페이지이면 영역 바닥 오른쪽에 둔다.

빈 상태

  • 빈 상태는 로딩, 없음, 오류 세 가지로 구분해 표시한다.
