    용어 · Element

    Element계열뜻
    ButtonButton글자가 있는 버튼. 디자인 시스템 유형은 primary, secondary, accent-outline, danger-outline, danger, quiet, ghost
    Text ButtonButton면과 테두리 없이 글자만 있는 버튼(디자인 시스템 Button 이 아닌 것)
    Icon ButtonIcon Button글자 없이 아이콘만 있는 버튼. 이름은 aria-label
    LinkLink다른 화면으로 이동하는 글자
    SelectSelect목록에서 값을 선택하는 드롭다운
    Text FieldText Input한 줄 입력칸
    Search FieldText Input검색어 입력칸
    Text AreaText Input여러 줄 입력칸
    CheckboxChoice켜고 끄는 네모 선택
    RadioChoice여러 값 중 하나를 선택
    Radio GroupChoiceRadio 묶음
    SwitchChoice활성화와 비활성화를 전환하는 토글
    StepperChoice수를 높이거나 낮추는 입력
    TabTab같은 화면 안의 보기 전환
    Heading-쪽, 영역, 창의 제목
    Subtitle-제목 옆의 부제
    Helper Text-제목이나 칸 아래의 안내 한 줄
    Info Icon-설명 툴팁을 여는 아이콘(Hint)
    Count-목록 제목 옆의 개수
    Tag-상태가 아닌 분류 표지
    Label-칸과 값의 이름표
    Value-이름표에 대응하는 값
    Optional Indicator-「선택 항목」 표시
    Character Counter-입력 글자 수
    Stat Label-지표 이름
    Unit-값의 단위
    Secondary Value-큰 값 옆의 보조 값
    Table Header-표의 열 이름
    Meta Text-카드 머리의 출처와 유형
    Owner-생성자 이름
    Title-카드의 이름
    Description-카드의 설명
    Card Body-누르면 상세로 이동하는 카드 본문
    Workspace Name-GNB 의 워크로드 이름
    Timestamp-GNB 의 마지막 수집 시각
    Logo-AGENTBASE 심볼과 워드마크
    Checklist Item-확인 표시와 이름, 값이 한 줄인 준비 항목
    Text-위에 들지 않는 글자

    용어 · Template

    Template한국어정의
    List Page목록 화면모듈의 작업이나 자원을 목록으로 조회하고 필터, 검색, 정렬을 적용한다.
    Status Page현황 화면자원, 사용량, 상태의 현황을 지표와 표로 조회한다.
    Create Dialog생성 창이름과 값을 입력해 작업, 자원, 폴더, 변수, 커밋, 그룹을 새로 생성하거나 등록한다.
    Edit Dialog수정 창생성한 항목의 값을 수정하거나 이름을 변경한다. 생성 창과 같은 칸을 같은 차례로 둔다.
    Duplicate Dialog복제 창원본의 설정을 그 유형의 수정 창과 같은 칸에 채워 열고, 이름과 바꿀 수 있는 값을 정해 새 작업을 생성한다. 바꿀 수 없는 값은 선택됨 + 비활성으로 보인다.
    Delete Confirm삭제 확인 창삭제 대상과 함께 끊기는 영향을 표시하고 삭제를 확정한다. 되돌릴 수 없는 삭제는 이름을 입력해 확정한다.
    Run Setup Dialog실행 설정 창실행 자원, 실행 시점, 반영 방식 같은 값을 정하고 배포하거나 실행한다.
    Action Confirm실행 확인 창배포, 발행, 오픈, 적용, 되돌리기, 교체처럼 상태를 바꾸는 동작을 한 번 더 확인하고 실행한다.
    Stop Confirm중지·해제 확인 창실행 중인 작업이나 배포의 중지, 연결과 오픈의 해제, 진행 중인 일의 취소를 확인한다. 끊기는 것은 빨간 경고로 적는다.
    Request Dialog요청 창권한이 없는 구성원이 요청할 값을 확인하고 요청 메모를 입력해 관리자에게 승인을 요청한다.
    Request Cancel요청 취소 창관리자에게 보낸 요청 중 승인을 기다리는 요청을 취소한다.
    Review Dialog검토 창관리자가 요청의 내용, 영향, 요청 메모를 확인하고 검토 메모를 적어 승인하거나 거절한다.
    Download Confirm다운로드 창다운로드할 파일이나 범위를 확인하고 다운로드한다.
    Leave Confirm나가기 확인 창저장하지 않은 변경이 있을 때 변경을 버리고 나갈지, 편집을 취소할지 확인한다.
    Progress Dialog진행 창업로드나 생성처럼 시간이 걸리는 일의 진행, 완료, 실패를 표시하고 진행 중인 일을 중지한다.
    Notice Dialog사유 안내 창작업이 실패하거나 대기하는 사유와 할 일을 안내한다.
    Picker Dialog선택 창대상을 선택해 불러오거나 이동, 복사한다.
    Settings Dialog설정 창연결, 연동, 메타데이터, 권한처럼 값을 설정하고 저장한다.
    View Dialog조회 창로그, 상세, 내역, 지표를 조회한다.
    Detail > Info상세 > 정보 탭작업의 기본 정보와 구성을 조회하고 수정, 삭제로 이동한다.
    Detail > History상세 > 이력 탭회차별 실행과 변경 이력을 조회한다.
    Detail > Monitoring상세 > 모니터링 탭호출, 성능, 자원 사용의 측정값을 기간별로 조회한다.
    Detail > Setup상세 > 설정·편집 탭학습, 검색 DB, 워크플로우, 파이프라인의 구성을 설정하고 편집한다.
    Detail > Evaluation상세 > 평가·테스트 탭평가와 테스트를 실행하고 회차별 결과를 조회한다.
    Side Panel패널화면 옆에 열려 노드와 항목의 속성을 설정한다.
    App Frame공통 영역모든 화면에 공통으로 표시되는 상단바, 좌측 메뉴, 편집 점유 표시다.
    Entry ScreenAGENTBASE 진입GPUBASE에서 AGENTBASE로 진입할 때마다 표시하는 스플래시다. 워크로드 이름과 준비 상태(GPU, CPU·RAM·스토리지, 구성원, 오케스트레이터)를 표시하고 홈으로 이동한다.
