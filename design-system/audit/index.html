용어 · Element

Element계열뜻
ButtonButton글자가 있는 버튼. 디자인 시스템 유형은 primary, secondary, accent-outline, danger-outline, danger, quiet, ghost
Text ButtonButton면과 테두리 없이 글자만 있는 버튼(디자인 시스템 Button 이 아닌 것)
Icon ButtonIcon Button글자 없이 아이콘만 있는 버튼. 이름은 aria-label
LinkLink다른 화면으로 이동하는 글자
SelectSelect목록에서 값을 선택하는 드롭다운
Text FieldText Input한 줄 입력칸
Search FieldText Input검색어 입력칸
Text AreaText Input여러 줄 입력칸
CheckboxChoice켜고 끄는 네모 선택
RadioChoice여러 값 중 하나를 선택
Radio GroupChoiceRadio 묶음
SwitchChoice켜짐과 꺼짐을 바꾸는 토글
StepperChoice수를 늘리고 줄이는 입력
TabTab같은 화면 안의 보기 전환
Heading-쪽, 영역, 창의 제목
Subtitle-제목 옆의 부제
Helper Text-제목이나 칸 아래의 안내 한 줄
Info Icon-설명 툴팁을 여는 아이콘(Hint)
Count-목록 제목 옆의 개수
Tag-상태가 아닌 분류 표지
Label-칸과 값의 이름표
Value-이름표에 대응하는 값
Optional Indicator-「선택 항목」 표시
Character Counter-입력 글자 수
Stat Label-지표 이름
Unit-값의 단위
Secondary Value-큰 값 옆의 보조 값
Table Header-표의 열 이름
Meta Text-카드 머리의 출처와 유형
Owner-생성자 이름
Title-카드의 이름
Description-카드의 설명
Card Body-누르면 상세로 이동하는 카드 본문
Workspace Name-GNB 의 워크로드 이름
Timestamp-GNB 의 마지막 수집 시각
Logo-AGENTBASE 심볼과 워드마크
Checklist Item-확인 표시와 이름, 값이 한 줄인 준비 항목
Text-위에 들지 않는 글자

용어 · Template

Template한국어정의
List Page목록 화면모듈의 작업이나 자원을 목록으로 조회하고 필터, 검색, 정렬을 적용한다.
Status Page현황 화면자원, 사용량, 상태의 현황을 지표와 표로 조회한다.
Create Dialog생성 창작업, 자원, 노드, 커밋을 생성하거나 등록한다.
Edit Dialog수정 창생성한 항목의 값을 수정하거나 변경한다.
Delete Dialog삭제 확인 창삭제 대상과 영향을 표시하고 삭제를 확정한다.
Action Dialog실행·중지·요청 창실행, 배포, 오픈, 중지, 해제, 취소, 승인 요청처럼 상태를 바꾸는 동작을 확정한다.
Picker Dialog선택 창대상을 선택해 불러오거나 이동, 복사, 다운로드한다.
Settings Dialog설정 창연결, 연동, 적용, 입력 값을 설정한다.
View Dialog조회 창로그, 상세, 내역을 조회한다.
Detail > Info상세 > 정보 탭작업의 기본 정보와 구성을 조회하고 수정, 삭제로 이동한다.
Detail > History상세 > 이력 탭회차별 실행과 변경 이력을 조회한다.
Detail > Monitoring상세 > 모니터링 탭호출, 성능, 자원 사용의 측정값을 기간별로 조회한다.
Detail > Setup상세 > 설정·편집 탭학습, 검색 DB, 워크플로우, 파이프라인의 구성을 설정하고 편집한다.
Detail > Evaluation상세 > 평가·테스트 탭평가와 테스트를 실행하고 회차별 결과를 조회한다.
Side Panel패널화면 옆에 열려 노드와 항목의 속성을 설정한다.
App Frame공통 영역모든 화면에 공통으로 표시되는 상단바, 좌측 메뉴, 편집 점유 표시다.
Entry ScreenAGENTBASE 진입GPUBASE에서 AGENTBASE로 진입할 때마다 표시하는 스플래시다. 워크로드 이름과 준비 상태(GPU, CPU·RAM·스토리지, 구성원, 오케스트레이터)를 표시하고 홈으로 이동한다.
